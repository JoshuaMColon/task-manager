# Life Planner Dashboard

A polished, responsive productivity dashboard built with HTML, CSS, and JavaScript. This project was designed to feel like a modern personal planning experience rather than a simple to-do list, combining thoughtful visual design with practical task management features.

## Project Overview

This project highlights front-end development skills through a complete, user-focused interface that balances aesthetics, usability, and functionality. The experience is built around a calm, homepage-style dashboard that makes planning feel approachable and motivating.

## What this project demonstrates

- Clean, semantic HTML structure
- Modern CSS styling with responsive layouts
- Interactive JavaScript for dynamic task behavior
- Local storage persistence for a smoother, more realistic user experience
- A strong emphasis on UI/UX and visual polish

## Core Features

- Create, edit, complete, and delete tasks
- Add due dates and priority levels
- Filter tasks by all, active, and completed views
- Track progress with a visual completion bar
- Switch between light and dark themes
- Deliver a responsive experience across desktop and mobile devices

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

- index.html — app layout and content structure
- style.css — visual design, layout, responsiveness, and theme styling
- script.js — task logic, rendering, persistence, and interactions

## How to Run

1. Open the project folder in your browser.
2. Launch index.html directly, or use a simple local server if preferred.

## Why it stands out

This project reflects a portfolio-ready approach to front-end development: strong visual design, attention to detail, clean code organization, and a clear focus on creating a refined user experience.
